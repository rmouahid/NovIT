# Guide utilisateur NovIT

## Démarrage rapide

### 1. Choisir ton profil
```
ETUDIANT  — apprentissage, curiosité, vulgarisation
INGENIEUR — technique, efficacité, précision
```
Dis à Claude : "Je veux utiliser NovIT" — il te demandera ton profil.

### 2. Choisir tes domaines
```
ia            Intelligence artificielle & ML
securite      Cybersécurité & CVE
dev           Développement logiciel
ingenierie    Architecture & infrastructure
reglementation  RGPD, AI Act, conformité
formation     Certifications & carrière
```

### 3. Lancer ta veille
```
"Quoi de neuf en IA aujourd'hui ?"
"Résumé de veille du jour"
"Dernières failles sécurité"
```

---

## Toutes les commandes

| Commande | Ce que ça fait |
|---|---|
| `novit news [domaine]` | Dernières actualités |
| `novit daily` | Résumé quotidien par domaine |
| `novit search [terme]` | Recherche dans les articles |
| `novit dig [url]` | Lire un article en profondeur |
| `novit related` | Articles similaires |
| `novit trends` | Sujets tendance de la semaine |
| `novit surprise` | Articles insolites |
| `novit health` | État du système |
| `novit help` | Afficher ce menu |

---

## Astuces

- **Filtrer par période** : "news IA des 6 dernières heures"
- **Changer de profil** : "passe en mode INGENIEUR"
- **Navigation** : "article suivant" / "reviens en arrière"
- **Mode debug** : "active le mode debug" pour voir les sources et timing
- **Alertes** : "alerte-moi si tu vois des articles sur Kubernetes"

## Confidentialité

NovIT ne stocke que les articles publics récupérés depuis des sources ouvertes.
Tes préférences sont sauvegardées localement dans `.novit_prefs.json`.
Aucune donnée n'est envoyée à un serveur externe.
