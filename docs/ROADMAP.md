# Roadmap — NovIT

> Lien vers les [milestones GitHub](https://github.com/LePhyX/NovIT/milestones)

---

## Ordre de développement

```
M0 (fondations) → M1 (MCP de base) → M2 (scrapers) → M3 (logique)
      ↓
M4 (prompts) → M5 (UX) → M6 (tests)
      ↓
M7 (doc) → M8 (collaboration) → M9 (release)
```

> **Note :** M6 (tests) et M7 (doc) doivent être alimentés **en continu** dès M1, pas seulement à la fin.
